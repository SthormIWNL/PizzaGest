## Objetivo do Software
O **PizzaGest** é uma aplicação desktop desenvolvida para otimizar a rotina operacional de pizzarias. O software serve para centralizar o controle de caixa, registrando de forma rápida e segura as movimentações financeiras de entradas e saídas, além de gerenciar cadastros essenciais do estabelecimento.

## Funcionalidades do Sistema (Requisitos)
- **RF01:** Tela de autenticação de acesso (Login) para operadores e gerentes.
- **RF02:** Registro de movimentações financeiras no caixa (Entradas e Saídas) com data automática.
